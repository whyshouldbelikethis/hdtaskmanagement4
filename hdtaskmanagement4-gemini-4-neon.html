Tài khoản Google đã kết nối

Hướng dẫn tạo Google OAuth Client ID (3 bước):
  1. Mở Google Cloud Console → tạo Project → vào APIs & Services → Library và bật Google Drive API.
  2. Vào OAuth consent screen (chọn External), thêm email của bạn vào mục Test users.
  3. Vào Credentials → Create Credentials → OAuth client ID (Web application), thêm Origin bên dưới vào Authorized JavaScript origins rồi copy Client ID dán lên trên.
